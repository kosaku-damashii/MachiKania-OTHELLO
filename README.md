# MachiKania-OTHELLO

MachiKania type Pで動作するオセロゲーム。<BR>
<BR>
・操作方法<BR>
タッチペンを使ってディスクの置き場所を指定する。<BR>
十字キーの操作で格子の数を変えることができる。<BR>
Blackが先行だが、FIREボタンを押下することで先行(Black)/後行(White)を選択できる。<BR>
STARTボタンを押下することゲームを開始する。<BR>
ゲームをスタートさせた後、置き場所が無くて先に進めない場合はFIREボタンを押下することでスキップできる<BR>
<BR>
･内部構造の説明<BR>
配列Pは､(N+1) x (N+1) のマトリックスになっているが、タッチペンで指定できる範囲は、0～Nの範囲で周囲の1升は常に0になっている。これは周囲にディスクがあるかどうかを判定する処理を簡略化するための工夫。
